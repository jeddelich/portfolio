# Copilot Instructions

## Project Overview
This project is a personal portfolio website built with React and Vite.
Code should prioritize readability, maintainability, and modular components.

## Tech Stack
- React (functional components with hooks)
- Vite for bundling
- CSS modules or standard CSS
- Deployed with Vercel

## Code Style
- Prefer simple, readable code over clever abstractions
- Use descriptive variable and function names
- Use modern ES6+ JavaScript
- Avoid unnecessary dependencies

## React Conventions
- Use functional components
- Prefer hooks for state and logic
- Keep components small and reusable
- Extract repeated UI into reusable components

Example:

function Navbar() {
  return <nav>...</nav>
}

## Styling Rules
- Prefer CSS variables defined in `index.css`
- Avoid hardcoding colors
- Use Inter as the default typeface for all text unless a file already requires a different font
- Use consistent spacing and layout
- Favor flexbox for layout

## File Organization
Follow this structure:

src/
  components/
    layout/
  pages/
  data/
  assets/
  styles/

## Best Practices
- Keep components under ~200 lines when possible
- Write clear JSX structure
- Use semantic HTML where possible
- Ensure components are responsive
